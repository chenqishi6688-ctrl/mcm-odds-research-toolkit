# MCM 赛事赔率研究工具包

这是一个面向足球赛事的、可审计的概率与市场结构研究工具。项目的核心不是“给出稳赢答案”，而是把不同来源的判断拆开、冻结、验证，并在证据不足时明确降级。

## 项目定位

MCM 严格区分三层概率：

1. **市场隐含概率**：从完整赔率市场去水后得到；
2. **独立竞技基线**：不使用正在审计的赔率，由赛前竞技数据生成；
3. **MCM 调整结论**：只有通过时间戳、独立性和矛盾检查的非市场证据，才允许调整第二层。

每场比赛最终只能处于以下状态之一：

- `FULL-MCM`：证据与审计门禁完整；
- `MCM-DEGRADED`：可运行，但存在重要证据缺口；
- `MARKET-STRUCTURE-ONLY`：缺少独立竞技基线，只能分析市场结构；
- `BLOCKED`：赛事身份、盘口方向、结算范围等关键输入未确认。

## 公开版包含什么

- 独立 Poisson 比分矩阵；
- 基于历史完赛数据的竞技基线构建器；
- 胜平负、整数三项让球、四档总进球和比分路径输出；
- 资本意图假设卡及“有/无资本层”的反事实比较；
- JSON 机器记录、校验器和冻结清单；
- 完全合成的端到端演示；
- 离线自动测试。

公开版不包含真实账号、密钥、资金数据、用户监控日志、个人路径或第三方专有数据。

## 快速运行

需要 Python 3.10 或以上版本，无需安装第三方依赖。

```bash
python -m unittest discover -s tests -v
python scripts/full_mcm_pipeline.py examples/synthetic-full-mcm-batch.json --output demo-run
python scripts/freeze_manifest.py demo-run
```

合成演示会诚实地产生 `MCM-DEGRADED`，原因是它没有真实、按时间点绑定的监控凭证。这正是门禁发挥作用的证明，而不是演示失败。

## 重要边界

- 赔率变动不是操纵证据；
- 低赔率不等于必然正确；
- 媒体热度不等于真实资金拥挤；
- 市场概率不能冒充独立模型概率；
- 历史命中个案不能直接升级为预测规则；
- 本项目不提供收益承诺或金融建议。
